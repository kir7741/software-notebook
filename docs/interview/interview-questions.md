# 面試考古題

### （ㄧ）、自我介紹

面試官好，我是 Joseph，目前是一名前端工程師，在軟體業大概有 8 年多的經驗，主要使用 Angular、React、Vue 等框架來開發產品與專案，而過去較常接觸的產業主要包含金融科技、教育，還有電商等。

我最早是在極限科技擔任前端工程師，公司的客戶主要是金融相關的產業，所以工作內容主要是用 Angular 來維護金融、保險客戶的內部系統跟後台管理平台。

後來我加入 25sprout，擔任資深前端工程師，除了一樣有使用 Angular 來開發保險產業的專案，也有負責用 React 跟 Vue 來開發電商平台以及其他客製化專案，過程中也常常跟 PM、設計師一起釐清需求、評估技術方案。後來因公司組織擴大與調整，我開始擔任前端副理，開始帶 5 到 6 人的前端團隊，開始負責專案的系統架構規劃跟任務拆解，還有協助新人上手專案並協助掌控團隊成員進度讓專案可以準時交付。而在此期間，我也有開發公司內部專用的套件，減少專案上的重複開發。

最近這兩年，我在 ViewSonic 擔任前端工程師，同時使用 Angular 跟 React 來負責開發與維護 VS Account、myViewBoard 等公司核心產品，服務對象主要是企業跟教育用戶。在 ViewSonic 這段期間，我跟設計師一起建立了內部的 Design System，製作 20 幾個可重複使用的元件，統一了產品間的設計標準，並提高了產品開發的效率。也更多的接觸了前端以外的領域，像是開始了解 CI/CD 流程，並能夠使用 AWS CloudFront 與 S3 部署前端專案，也有使用 NestJS 開發後端 API 的經驗，並且也有使用像是 Claude Code, OpenSpec 等 AI 工作流來輔助開發。

整體來說，我擁有一定的前端技術經驗，能夠快速上手各種前端開發工具，並且對後端技術也有一定的了解。另外，也時常擔任跨部門溝通的角色，希望能夠加入貴團隊，一起開發產品。

### （四）、跨部門合作經驗／分派人力資源的經驗

(一)、與 PM 拆解問題、討論需求、並提供技術上的建議，像是金流與購物模組的串接、複雜表單的規劃、以及 GTM 埋碼的流程

(二)、與設計師討論 UI/UX，像是登入模組、表單的操作流程。

(三)、與後端工程師討論 API 的串接、資料結構的規劃與技術選擇，還有像是需要等待後端完成的功能要使用 websocket, SSE 還是 polling，還有像是 RESTful API 與 GraphQL 的差異。

(四)、分派人力資源的經驗，首先是區分事情的重要緊急程度、再來是判斷團隊成員的 loading 最後再依照每個人的專長與能力去分派任務。
